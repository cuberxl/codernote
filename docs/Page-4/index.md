### 变量类型

| 类型 | 标识符 | 占字节数 | 数值范围/有效位数 |
| :--- | :--- | :--- | :--- |
| 整型 | `short` | 2 (16位) | `-2^15 ~ 2^15 - 1` |
| 整型 | `int` | 4 (32位) | `-2^31 ~ 2^31 - 1` |
| 整型 | `long` | 4 (32位) | `-2^31 ~ 2^31 - 1` |
| 整型 | `long long` | 8 (64位) | `-2^63 ~ 2^63 - 1` |
| 浮点型 | `float` | 4 (32位) | 6-7位 |
| 浮点型 | `double` | 8 (64位) | 15-16位 |
| 浮点型 | `long double` | 16 (128位) | 18-19位 |
| 字符串型 | `char` | 1 (8位) | `-128~+127` |
| 布尔型 | `bool` | 1 (8位) | 0或1 |
| 无类型 | `void` | 无 | 无 |
